# Media Backup

## Overview
This project enables you to host your own photo and video storage server and connect to it via an android app or through a website.

## Components
- [Backend](https://github.com/LewisSSmith/MediaBackupServer)
- [Android App](https://github.com/LewisSSmith/MediaBackupAndroidApp)
- [Website](https://github.com/LewisSSmith/MediaBackupWebsite)
